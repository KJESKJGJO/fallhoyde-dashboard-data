# Fallhøyde – datafeed

Offentlig datafeed for [Fallhøyde](https://) drawdown-dashboardet (Oslo Børs).
Filene her oppdateres automatisk hver dag og inneholder kun offentlig
markedsdata (daglige sluttkurser) og lenker til offentlige nyhetsartikler.
Ingen personopplysninger lagres her.

- `drawdown_stats.json` – maks drawdown per aksje
- `price_series.json` – daglige sluttkurser per aksje
- `events.json` – nyheter/hendelser knyttet til kursfall
- `meta.json` – tidspunkt for siste oppdatering
